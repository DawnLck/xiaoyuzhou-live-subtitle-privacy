Chrome 浏览器扩展
最后更新：2026 年 10 月 21 日（适用于 0.1.1 版）

一句话版本：本扩展没有服务器，不收集你的任何数据。密钥、字幕缓存、收藏和界面偏好全部存在你自己的浏览器里，卸载即删除。

我们收集什么

小宇宙跟读（以下简称「本扩展」）没有自己的服务器，不会收集、存储或接收你的任何数据。开发者无法看到你的密钥、你收听的内容，或任何识别结果。

本扩展在你的浏览器本机保存以下内容：

内容存放位置用途
阿里云百炼 API Keychrome.storage.local向阿里云发起识别请求时作为身份凭证
已识别的字幕片段IndexedDB再次收听同一段时不重复识别
收藏的单集、关注的节目、摘录的句子chrome.storage.local在侧边栏收藏夹里回听和查找
收听断点（最近 200 期）chrome.storage.local「继续收听」，从上次停下的地方接着听
侧栏宽度、倍速、波形显隐chrome.storage.local记住你的界面设置

以上数据全部存于你自己的浏览器中，卸载扩展即一并删除。

数据会发送到哪里

本扩展只向以下地方发起网络请求：

1. 小宇宙音频与图片 CDN（*.xyzcdn.net）
按 HTTP Range 请求你当前播放位置附近的音频片段，用于切片识别，不下载整集；侧边栏收藏夹会加载单集和节目的封面图。

2. 小宇宙网页（www.xiaoyuzhoufm.com）
读取公开的单集页、节目页，获得标题、封面等信息；对你关注的节目，每 6 小时读取一次节目页，检查是否有新单集。这些请求不携带你的 Cookie 或登录状态，小宇宙看到的只是一次普通的公开页面访问。

3. 阿里云百炼（dashscope.aliyuncs.com / *.aliyuncs.com）
使用你自己的 API Key，将上述音频片段上传并提交语音识别，再取回带时间戳的文字。这是识别服务的必要步骤。你的 API Key 仅作为请求的身份凭证发送给阿里云，不会发送给本扩展作者或任何其他方。

阿里云对这部分数据的处理，适用阿里云自己的隐私政策：阿里云隐私权政策。

本扩展不包含任何统计、埋点、广告或第三方分析代码。

你的控制权

  • 随时在扩展设置中清空 API Key
  • 在侧边栏随时取消收藏、取消关注、删除摘录；取消关注后不再检查该节目的更新
  • 卸载扩展会删除全部本地数据（密钥、缓存、收藏、偏好）
  • 不填写 API Key 时，扩展不会向阿里云发起任何请求；播放器、波形、倍速等功能仍可正常使用
